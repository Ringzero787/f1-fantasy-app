# docs

| Document | What it is |
|---|---|
| `RUNBOOK.md` | How to do the recurring jobs: a feature, a release, a production operation, a race weekend |
| `design/pitwall/` | Pit Wall: `README.md` (what it is and where its parts live), `ARCHITECTURE.md`, `RESEARCH.md`, the projection backtests, the Briefing redesign |
| `design/grid/` | The Grid redesign of the app's screens, with verification screenshots |
| `design/moonshot/` | The Moonshot specification |
| `store/` | Store listing copy for Play, the App Store and Amazon, and the Pit Wall Pass store setup |
| `pricing-rules.txt`, `pricing-rules-v2.txt` | **Out of date.** Early pricing write-ups; the live rules are in `functions/src` and `src/config/pricing.config.ts` |
| `archive/` | Superseded and handoff documents; the Markdown ones carry a banner saying so. Kept for the reasoning, not for the facts |

Feature specs are not here: they live beside the registry in `.aidlc/specs/`. Decisions are in `.aidlc/decisions/`.

A document that describes a plan is archived once the plan is built. Current state belongs in the registry, not in a dated paragraph of a README.
