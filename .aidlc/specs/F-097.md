# F-097 — UC: Pit Wall Briefing redesign (hero, calls strip, Archivo type and tokens portal-wide)

Created: 2026-10-04 · Status: building

## Goal
Undercut (root app), Pit Wall portal only. The owner's design handoff of 2026-10-04 (`docs/design/pitwall/briefing/`) gives the Briefing the shape of the mobile app: a hero with the team name and season numbers, a weekend card, a strip of "calls" that peek on hover, lock on click and expand to the full comparison, lineup tiles and price movers, all in Archivo wide display type with a revised token set. This feature applies it in stages without breaking the portal's rules: the three-screen scroll budget on phones, one type system across all eight pages, the free/pass gating, and the frames the spec already requires.

## Acceptance criteria
Stage 1 — type and tokens, portal-wide
- [ ] Archivo (width 125, weights 700/800/900) replaces Unbounded as the display face on every page, with JetBrains Mono for labels and body; `font-stretch` is carried wherever a `font` shorthand would reset it. Google Fonts is the only font host.
- [ ] Tokens in `web/pitwall/src/styles.css` take the handoff values for dark and light (background, surfaces, raised cells, text, muted, dividers, accent, ink on accent, positive); light mode keeps a straight inversion. No colour is defined only inside a media or `[data-theme]` block.
- [ ] The scroll-budget test passes on every page, state, size and scheme after the change, and no page overflows sideways.

Stage 2 — Briefing hero and weekend card
- [ ] The Briefing opens with the hero: team name (the real team, or the example team), team switcher when the user owns more than one team, season points, last race, league rank and bank, and the red-outlined weekend card (projected points with range bar, Rate My Team, flags, Open Lineup Lab). The sticky shell (top bar, round strip, nav) is unchanged on every page; the hero renders only on the Briefing.
- [ ] Numbers come from the same sources the context bar and the current Briefing use; a value not available for this user shows a dash, never an example number next to real ones.
- [ ] Phone: the hero fits in about one screen; the whole Briefing stays within three screens in every state the test measures, including bare and free-look.

Stage 3 — the calls strip
- [ ] The recommendation list and side panel become a strip of call tiles (tag, title, meta, note) built from the existing `briefRecs`, so swap calls appear when the lineup is open and the ace/hold/risk/team calls when it is locked. Each tile carries the confidence lean from F-096.
- [ ] Hover (or focus) on a tile with comparison data shows a peek callout; click locks it (accent border, lock mark). The locked callout leads with the recommendation's own action as its largest control — make the swap (a what-if carried into the Lineup Lab; on a locked weekend labelled as planned for the next round), set the ace (written at once; disabled once the race has started), or "No change needed" — with a smaller "All stats" beside it and a close control. All stats shows the full comparison in flow under the strip with the same action; Collapse returns to the locked callout; clicking the locked tile unlocks. Peek is suppressed while another tile is locked. Tiles without comparison data only lock.
- [ ] On phones (no hover) click opens the comparison in the slide-over, as today. Keyboard: tiles are buttons, Escape unlocks, focus is visible.
- [ ] Without a pass the strip shows the locked treatment with the pass offer; the free look is unchanged.

Stage 4 — lineup tiles, movers and the wire
- [ ] Lineup tiles (2×3, ACE pill, team bar, projected points and the predicted price move, which is what the portal has; open seats drawn as such) sit beside the wire on wide screens; on phones they are left out, since the Lineup Lab is one tap away and the Briefing has no room for them inside the budget. The wire keeps the vote and mark-read controls; five headlines on a phone, ten on a desktop; rivals' likely moves, weather and the free top ten remain.
- [ ] Verified with screenshots of dark and light at 1440×900 and 390×844, plus the expanded comparison, committed under `docs/design/pitwall/briefing/verify/` (`tests/out/` is ignored).

## Data
No new user data. Reads the same team, league and payload documents the portal reads today.

## Performance budget
First-load JS unchanged (fonts are a stylesheet link); the font request adds one family and drops one. Scroll budget: ≤ 3.0 screens on every page at 1440×900 and 390×844.

## Out of scope
- Changing the mobile app's typeface (a separate decision for the next app release).
- The SHARE action on the lineup (share cards are F-065).
- New data the handoff draws but the worker does not publish (nothing is invented to fill a tile).
