# F-048 — UC: Android release target (uc-android)

Created: 2026-09-17 · Status: planned

## Goal

Undercut 2.2.3 had to be built by hand (bump two files, reuse a prebuilt `android/` because `expo prebuild --clean` wipes the release signing, gradle, verify, copy) while Track Limits releases are one command. This wires the same flow for Undercut: a root `plugins/withReleaseSigning` config plugin that re-injects the Undercut keystore into `android/app/build.gradle` at prebuild (password from `UC_KEYSTORE_PASSWORD` or the untracked `.signing.env`), `scripts/release/build-uc-aab.sh` mirroring the TL script, and the `uc-android` target on the `undercut` release unit.

## Acceptance criteria
- [ ] `aidlc run --tier release --unit undercut --version X.Y.Z` runs `uc-android`: bumps `app.config.js` (version + versionCode), prebuilds Android clean, builds the release AAB, and copies it to `/mnt/smb/share/undercut/` and the Windows upload box as `undercut-X.Y.Z-vc<vc>.aab`.
- [ ] After `expo prebuild --platform android --clean`, `android/app/build.gradle` has a `release` signing config pointing at `undercut-release.keystore` (alias `undercut`) and `buildTypes.release` uses it; the built AAB's certificate is `O=Undercut`.
- [ ] The build fails (non-zero) if the AAB is debug-signed, if its JS bundle lacks the `(simple)` routes or contains Track Limits routes, or if the seven Race Day font files are missing from the native assets.
- [ ] `UC_SKIP_PUBLISH=1` builds and verifies without copying anywhere.
- [ ] `expo export` / `expo config` (CI, no keystore password) still succeed: the password is read only inside the build.gradle mod.
- [ ] `node --test plugins/*.test.js` passes and is part of the repo test gate.
