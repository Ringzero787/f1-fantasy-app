# F-147 — UC: ops check off-season mode

Created: 2026-11-14 · Status: implemented

## Goal

The Pit Wall check (F-132) runs hourly and, with F-140 on, emails the owner on a FAIL. After the
final round nothing in the registry is upcoming, and the check FAILed "no upcoming race", so it
would have emailed every hour from Abu Dhabi until the 2027 calendar is seeded. In the off-season
the check now reports the last scored round, accepts a payload of any age on that round, and keeps
every other check: a hung worker, an unscored final round, a stuck queue and an empty registry
still FAIL.

## Acceptance criteria
- [x] Every race completed or cancelled, portal on the last round, worker ticking → OK, whatever the payload age (test `off-season: the last round…`).
- [x] Off-season with a hung worker → FAIL; portal on an older round → WARN (test `off-season: a hung worker…`).
- [x] A final round that raced and is still `upcoming`, or an empty registry → FAIL (test `off-season does not hide…`).
- [x] Still off-season 75 days after the final round (the calendar was never seeded) → WARN in the twice-weekly report, not a FAIL email (test `off-season: a calendar still unseeded…`).
- [x] In-season behaviour unchanged: the existing 16 tests pass and the live run on 2026-11-14 is OK on round 23.

## Targets
- ops script on the box (`scripts/ops/pitwall-check-lib.js`), run by cron from the `/data/f1-app-openf1` checkout. No deploy.
