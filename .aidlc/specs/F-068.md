# F-068 — UC: Pit Wall Pass entitlement and web checkout

Created: 2026-09-19 · Status: planned

## Goal
Undercut (root app). Pit Wall Pass is the per-user premium that sits beside League Pro (per-league). Selling it on the web through Stripe keeps about 97% of the price instead of 70-85%, and gives Amazon users a way to pay. Playing the game stays free.

## Acceptance criteria
- [ ] Two web prices via Stripe Checkout: season pass (launch $29.99, valid through the final round of the season) and monthly ($4.99). Comparable tools sit at EUR 3-8 per month or 25-60 per season; betting-tool pricing is out of range for this audience.
- [ ] Stripe webhook (signature-verified Cloud Function) writes a server-owned `users/{uid}.pass = { tier, season, expiresAt, source }`; rules deny client writes (rules test). Webhook handling is idempotent on event id.
- [ ] The same pass can be bought in the Play and iOS apps as an IAP through the F-060 validation path, writing the same field. The iOS app shows no link or wording that steers to web checkout unless current App Store rules for the storefront allow it (checked at release).
- [ ] Free teaser set, visible without a pass: Briefing headline cards, Board with median projection only for the top 10 rows, Wire headlines, and the user's own lineup read-only. Everything else shows a locked state with the pass offer. Gating is enforced in Firestore rules on the analytics documents, not only in the UI.
- [ ] Members of a League Pro league get a one-time 7-day pass trial (drives both products).
- [ ] Refund/cancel from Stripe revokes at period end; an admin op can grant or revoke a pass.
- [ ] Stripe Tax enabled before launch; terms and privacy pages updated for web payments.

Stripe customer id and pass status on the user document. Card data never touches our servers (Stripe Checkout).
