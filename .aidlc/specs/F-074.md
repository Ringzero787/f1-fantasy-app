# F-074 — UC: Pit Wall market and season outlook

Created: 2026-09-19 · Status: planned

## Goal
Undercut (root app). The long-game pages: where prices and ownership are heading, and what the rest of the season looks like for each car and for the user's team value.

## Acceptance criteria
- [ ] **Market:** price movers and predicted changes (threshold points per price step, P(rise)/P(fall), expected change); value board (points per $ season and last three); ownership and ace-weighted effective ownership in the user's leagues with each asset classed as threat or differential; leverage (ownership rank minus ceiling rank); template team among top-ranked managers.
- [ ] **Season:** schedule difficulty ticker (assets x next N rounds coloured by circuit-fit, sprint weekends flagged); power rankings with movement; title simulation fan chart and finishing-position distribution; reliability and penalty tracker (power-unit component matrix against allocation, "penalty likely" badge, DNF rate by cause).
- [ ] **My performance:** team value growth curve, points vs optimal and vs template, league rank trace with rival tracking.
- [ ] Alerts (email and app push, user-selectable): price threshold, projection swing after a session, penalty confirmed, rain probability crossing a set level, lock reminder with open slots.
- [ ] Follows the F-075 scroll budget and click-in rules; every frame has a table view and "data as of".

## Targets
- web
- firebase (functions)

## Data
League ownership is shown only for leagues the user belongs to. Alert preferences stored on the user document.

## Performance budget
<= 12 reads per page; alert fan-out batched per session.

## Out of scope
- Public global ownership leaderboards.
