# F-064 — UC: League Pro custom scoring

Created: 2026-09-18 · Status: planned

## Goal
Undercut (root app), League Pro only. `settings.scoringRules` exists on league documents but the server ignores it. Pro commissioners can pick a scoring preset or adjust bounded weights, and their league table is ranked on that scoring, while global standings and prices stay on standard scoring for everyone.

## Acceptance criteria
- [ ] Presets (Standard, Qualifying-heavy, Sprint-heavy, No-DNF-penalty) plus bounded per-category multipliers are validated server-side by a callable; out-of-range values are rejected.
- [ ] Scoring computes a league-scoped points total for Pro leagues with non-standard rules, stored separately from `totalPoints`/`lockedPoints`; the banked/active model and global leaderboard are unchanged (regression test on an existing race fixture).
- [ ] Rule changes apply from the next unscored race only; past races are never rescored, and the change is recorded in a league audit entry visible to members.
- [ ] League table, F-062 race results and F-063 fixtures use the league-scoped points when present.
- [ ] Non-Pro leagues with a `scoringRules` value are scored as Standard.
- [ ] The Rules Guide shows the league's active rules, not only the global table.

## Targets
- firebase (functions, rules)
- android
- ios

## Data
League settings and an audit entry (uid of the commissioner who changed rules).

## Performance budget
Scoring run time +<10% with 100 Pro leagues (measured on the scoring unit-test fixture).

## Out of scope
- Custom driver prices or budgets per league.
- Free-form formula editing.
