# F-033 — Repo hygiene: tracked stray files

Created: 2026-09-11 · Status: building (keystore passwords first)

## Goal
Both apps' release keystore passwords are committed in this public repo — Track Limits in `newgame/plugins/withReleaseSigning.js`, Undercut in `scripts/fix-android-build.sh`. The keystore files themselves are not public, but the passwords should not sit next to the code that uses them. This first slice of F-033 moves them to an untracked, owner-only `.signing.env` on the build box (or the environment), read only when an Android release is being prepared, and makes the builds fail loudly when it is missing. The rest of F-033 (the ~350 untracked root artifacts) stays planned.

## Acceptance criteria
- [ ] Neither password appears in any tracked file at HEAD (`git grep` for both values returns nothing).
- [ ] `.signing.env` is gitignored; it holds `TL_KEYSTORE_PASSWORD` and `UC_KEYSTORE_PASSWORD` as KEY=VALUE lines and is parsed, never shell-sourced (the Undercut value contains `$`, `!`, `#`).
- [ ] The Track Limits plugin takes the password from `TL_KEYSTORE_PASSWORD` in the environment first, then `.signing.env`; unit tests cover environment, file, missing (clear error) and a value containing a quote or backslash (refused).
- [ ] The password is read only inside the build.gradle mod: evaluating the Track Limits config (`expo config`, as CI's `expo export` does) succeeds with no `.signing.env` present.
- [ ] An Android prebuild on the build box writes the same release signing block as before (same keystore path, alias and password), so the next release AAB still verifies as `CN=TrackLimits`.
- [ ] `scripts/fix-android-build.sh` reads `UC_KEYSTORE_PASSWORD` the same way and exits with a clear message when it is missing.

## Targets
- android: release signing for Track Limits (`newgame/plugins/withReleaseSigning.js`) and Undercut (`scripts/fix-android-build.sh`); CI hygiene gains the plugin tests.

## Data
No user data. Moves two build secrets out of git into an untracked file on the build box.

## Performance budget
n/a — build-time only.

## Out of scope
- Rewriting git history: the old values stay in past commits. Fully closing the exposure means resetting the Play upload keys in Play Console (the owner's call; not needed for this change).
- The other stray untracked files at the repo root (rest of F-033).
- iOS signing (certificates and profiles live on the Mac Mini, not in the repo).
