# F-061 — UC: League Pro upgrade screen and free-tier changes

Created: 2026-09-18 · Status: planned

## Goal
Undercut (root app). Commissioners see what League Pro adds and can buy it from the Grid League Manager; members see that their league is Pro. At the same time the old paywalls that taxed growth go away: creating leagues is free and unlimited, and the +20 member expansion becomes part of Pro.

## Product decisions (owner, 2026-09-19)
One premium product: **Pit Wall Pass, $14.99 per season, per user** (`pitwall.pass.season`). It includes the full Pit Wall portal and League Pro for every league the holder owns. No monthly price, no separate League Pro purchase. Playing, creating leagues and a free look at the portal (including Rate My Team and the timing-derived frames) stay free. See `.aidlc/decisions/ADR-001-pit-wall-pass-and-timing-data.md`.

## Current state (verified 2026-09-19)
No purchase has ever been made (production `purchases` is empty, no league expanded) and the purchase library has been absent since v2.1.0, so the three existing products can be retired without migrating anyone.

## Acceptance criteria
- [ ] An in-app purchase library is a declared dependency again, in the Google Play and iOS builds only. The uc-amazon build must not contain Play Billing (the reason it was dropped in v2.1.0): either a build flavour/plugin excludes it or the module is proven absent from the Amazon APK (checked in the release target).
- [ ] `purchase.store.ts` no longer relies on a `require` that can silently fail: if the purchase module is missing in a Play/iOS build the release gate fails, rather than the user seeing "not available".
- [ ] `league.expansion`, `avatar.pack` and `league.slot` are removed from `src/config/products.ts` and the UI; persisted local credits from old state are ignored without error. AI avatar generation keeps its existing free allowance.
- [ ] Grid League Manager shows a League Pro card: benefits list, "Included with Pit Wall Pass" and the pass upgrade action for the owner, "Ask your commissioner" for members, and a PRO badge once `isLeaguePro` is true. The upgrade action is the same upgrade sheet as the Profile row (F-068); there is one purchase flow in the app.
- [ ] The entitlement is read from the league document and the user's pass, never from local persisted state.
- [ ] League creation no longer checks `leagueSlotCredits`.
- [ ] Pro leagues have `maxMembers` 100; the capacity change is made server-side when Pro is granted (F-060, consistent with F-059), never by the client.
- [ ] Amazon build (uc-amazon) hides BUY and shows "Upgrade from the Android or iOS app"; it honours an existing entitlement.
- [ ] Demo mode can toggle Pro locally without touching Firestore.
- [ ] Copy contains no trademark watchlist terms in the product or tier name.
- [ ] Verified with the Expo web + Playwright recipe: free league owner, free league member, Pro league.
