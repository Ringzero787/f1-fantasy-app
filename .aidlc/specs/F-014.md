# F-014 — TL: Release signing plugin (extension: local release build)

Created: 2026-09-11 · Status: building

## Goal
Track Limits releases were built by hand from a recipe spread across notes: prebuild, gradle with the lint pass skipped, check the signer, check the bundle is Track Limits' and not Undercut's (vc28 shipped Undercut's JS and crashed on open), bump version and versionCode (Play burns every code it sees), copy the AAB to the share and the Windows upload box. The AIDLC config still pointed release builds at EAS, which this project never uses. This extension makes a Track Limits release one command on the build box — `aidlc run --tier release --unit tracklimits --version X.Y.Z` — using the engine's release units, so the version, build, checks, notes, changelog and registry all come from the same run, and Undercut releases stay separate.

## Acceptance criteria
- [ ] `.aidlc/aidlc.yaml` defines release units `tracklimits` (tag prefix `tl-v`, paths `newgame/`, changelog `newgame/CHANGELOG.md`, target `tl-android`, features `TL:`/`Repo:`, patch bumps) and `undercut` (tag prefix `uc-v`, Undercut paths, root `CHANGELOG.md`, no build targets yet, features `UC:`); no build target references EAS.
- [ ] `scripts/release/bump-app-version.js` sets `version` and moves `versionCode` up by exactly one, keeps the code when re-run for the same version, and refuses an older version; unit tests cover all three.
- [ ] `scripts/release/build-tl-aab.sh` fails unless `AIDLC_RELEASE_VERSION` is set, and fails the build when the AAB is not signed `CN=TrackLimits` or its JS bundle lacks `(tabs)/garage.tsx` or contains Undercut routes (`my-team.tsx`, `(simple)`).
- [ ] A local run of the build script with `TL_SKIP_PUBLISH=1` produces a signed Track Limits AAB that passes both checks and copies nothing to the share or the upload box.
- [ ] `aidlc run --tier release --unit tracklimits --dry-run` lists the release gates for the unit; `--unit undercut` builds nothing.

## Targets
- android: Track Limits release AAB (local gradle build on the Linux build box); release records for both apps.

## Data
No user data. Build artifacts go to the SMB share and the Windows upload box as before.

## Performance budget
