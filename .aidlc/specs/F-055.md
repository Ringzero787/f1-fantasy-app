# F-055 — UC: Grid Pick Team screen

Created: 2026-09-18 · Status: planned

## Goal

The Market panel becomes the Grid "Pick Team" screen (`app/(simple)/picker.tsx`), pushed from the Team screen's `EDIT →` and open slots. Players see the whole grid in one list per sub-tab (DRIVERS / CONSTRUCTOR), tap rows to build a lineup, and commit once with SAVE LINEUP. The four mechanics the prototype omits are built from TRANSITION.md §1: the $1,000 budget with per-row prices, the 1–6 race contract chosen in a bottom sheet on add, the Ace toggle, and a save summary that lists sells with early-termination fees before anything is written.

## Acceptance criteria
- [ ] Header: `← CANCEL` (pops without writing), red lock status, title `Pick Team` / `Locked`, `n/5 · c/1` counter (green when complete). Budget line under the header: `BUDGET $877` mono, red below $50, computed from the pending lineup (bank + pending sells − pending buys).
- [ ] Rows follow §4 (`36 px | name + colour bar + team | pts + trend | 28 px ring`) plus a mono price column; rows the pending budget can't afford, rows blocked at 5/5, locked-out drivers (`driverLockouts`) and everything when locked render at 35 % opacity and ignore taps.
- [ ] Sort toggle `PTS / $` in the tab row; no search box.
- [ ] Tapping an unselected driver opens the contract sheet: name, price, 1–6 segmented chips (default `PRICING_CONFIG.CONTRACT_LENGTH`), red ADD. Tapping a selected driver marks it for sale (ring clears). Constructor tab is single-select.
- [ ] Save button states: `PICK n MORE` (card/muted) while incomplete, `SAVE LINEUP` (red) when 5 + 1, `LOCKED · AUTO-FILL ON` when locked. Tapping SAVE with any pending sell shows a summary sheet: each sell with sale price and early-termination fee from `estimateSaleQuote`, each buy with price and contract, resulting bank; CONFIRM applies the changes.
- [ ] Applying uses the existing server-authoritative callables in order (sells first, then buys, then constructor); a failed step surfaces its message and leaves the lineup as the server returned it. Ace changes go through `setAce` / `setAceConstructor` / `clearAce` and are hidden when `aceLocked`.
- [ ] `planLineupChanges(current, pending, prices)` and `pendingBudget()` are pure helpers in `src/simple/grid/` with jest coverage: no change, add within budget, add over budget blocked, sell with fee, swap, constructor replace, locked.
- [ ] `SimpleMarketPanel`, `SimpleMarketRow` and `SimpleContractPicker` are deleted once the picker is wired.
- [ ] `npx tsc --noEmit` and `npx jest --ci` pass; `npx expo export --platform android` succeeds.
