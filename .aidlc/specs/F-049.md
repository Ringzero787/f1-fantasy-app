# F-049 — UC: Amazon and iOS release targets (uc-amazon, uc-ios)

Created: 2026-09-17 · Status: planned

## Goal

F-048 made the Play build one command; Amazon and iOS were still by hand (the 2.2.3 Amazon APK and iOS build 37 were built manually, and iOS needed three attempts to find a signing recipe that works over SSH). This wires both as release targets so `aidlc run --tier release --unit undercut --version X.Y.Z` produces all three store artifacts, and captures the iOS recipe in a script instead of a memory note.

## Acceptance criteria
- [ ] `scripts/release/bump-app-version.js` also moves `ios.buildNumber` by one on a new version and keeps it on a re-run; `--ios` prints the build number instead of the version code. Three targets in one release bump exactly once.
- [ ] `uc-amazon` (`scripts/release/build-uc-apk-amazon.sh`): prebuild and gradle with `EXPO_PUBLIC_STORE=amazon`, `assembleRelease`, verify with apksigner (`O=Undercut`), the Undercut bundle, no Google sign-in native module, the Amazon sign-in path present, seven fonts; copy as `undercut-X.Y.Z-vc<vc>-amazon.apk` to the share and the Windows box. `UC_SKIP_PUBLISH=1` builds and verifies only.
- [ ] `uc-ios` (`scripts/release/build-uc-ios.sh` + `scripts/release/mac/uc-ios-archive.sh`): pre-checks (untracked configs, Mac reachable, cert files on the Mac), rsync the tree to the Mac, then on the Mac: `npm ci --legacy-peer-deps`, `expo prebuild --platform ios --clean`, `pod install`, temporary unlocked keychain from `~/ZP6VK29GWR.{cer,p12}`, manual signing on the app target only, archive, export with a manual app-store-connect plist, verify Info.plist version/build/bundle id and the embedded profile, upload with `xcrun altool --upload-app` unless `UC_SKIP_PUBLISH=1`, copy the IPA back to `/mnt/smb/share/undercut/undercut-X.Y.Z-build<n>.ipa`, restore the keychain list.
- [ ] `.aidlc/aidlc.yaml`: `uc-amazon` and `uc-ios` targets; the `undercut` unit runs `[ uc-android, uc-amazon, uc-ios ]`.
- [ ] `node --test scripts/release/*.test.js` covers the buildNumber bump and syntax-checks every release script.
