# F-087 — UC: Share your team from the Team screen

Created: 2026-10-02 · Status: building

## Goal
Undercut (root app). F-083 let someone share the league table, which answers "how is everyone doing". This is the other half of the same conversation: somebody posts their own lineup and the group tells them the ace is wrong.

A SHARE control beside EDIT on the lineup row hands the team to the operating system's share sheet as text, for the same reasons F-083 chose text — it pastes into Slack, a text message and an email alike and needs nothing native behind it.

## Acceptance criteria
- [x] SHARE sits beside EDIT on the lineup row, and is offered only when the roster actually holds something. `computeTiles` pads to a fixed size with empty placeholders, so the array length is a constant and cannot gate anything — a brand-new team with nothing picked must not get a control that silently does nothing.
- [x] It shares what the screen is showing: the same round, the same ace.
- [x] The message leads with the team name and the round, then a summary line, then one line per driver and the constructor.
- [x] **The ace is marked.** It is the single most argued-about choice, so it is the one thing that has to survive the trip into a message. With no ace, the column is not drawn at all rather than left empty.
- [x] The summary carries only what exists: no last race before the round is scored, no rank outside a league, rather than a row of dashes.
- [x] Every line inside the same 34 display-column budget as F-083, measured in columns rather than characters, reusing `shareStandings` rather than restating it.
- [x] Both share screens go through one helper for the sheet itself, so what counts as a dismissal and what gets logged cannot drift between them.

## Targets
- android
- ios

## Data
The shared text contains the player's **own** team: team name, season points, last race points, league rank and size, and for each driver and the constructor their name and points. It contains nothing about any other player, which is the difference from F-083 — that one carries other league members' display names and needed a privacy read; this one does not.

## Performance budget
No new dependency. One pure function over at most seven rows, run once per share.

## Out of scope
- Sharing another player's team.
- Prices, contracts and trends. A team of six fits on any screen; padding it with fields nobody reads is how it stops being readable.
- Localization. The new strings are English, and `src/simple/**` is not yet in `localization.scan`; they belong to the F-079 pass along with F-083's.
