# F-065 — UC: League Pro season recap and awards

Created: 2026-09-18 · Status: planned

## Goal
Undercut (root app), League Pro only. After each race and at season end, a Pro league gets a recap worth sharing in the group chat: who won, best pick, biggest climb, season awards. Every share card carries the league invite link, so the feature doubles as the acquisition loop.

## Acceptance criteria
- [ ] Server builds a per-race recap document for Pro leagues from F-062 results (winner, top-scoring pick, biggest position gain, worst luck/DNF).
- [ ] A season awards page lists champion, most race wins, best single race, best value pick and wooden spoon once the final race is scored.
- [ ] Recap renders as a share card image (native share sheet) containing the league name and invite deep link; no team liveries, logos or watchlist terms in the artwork.
- [ ] Non-Pro leagues see the race winner only (F-062) with an upsell row for the full recap.
- [ ] Recap generation is idempotent on re-score.

## Targets
- firebase (functions)
- android
- ios

## Data
Derived league results; shared image leaves the device only when the user shares it.

## Performance budget
Recap built once per Pro league per race; image rendered on device, bundle +<40 KB.

## Out of scope
- AI-written commentary.
- Email delivery of recaps.
