# F-148 — UC: dependency security pass retires the blanket GHSA waiver

Created: 2026-11-14 · Status: shipped (OP-225 functions, OP-226 portal, 2026-11-14)

## Goal

Since 2026-09-18 a blanket G05 waiver (`finding: GHSA-`) has hidden every dependency advisory in
the repo, about 200 of them, many HIGH in runtime packages (body-parser, @fastify/busboy,
node-forge, ws, @grpc/grpc-js, sharp). It expires 2026-12-15, and the 2.8.0 release sign-off made
this pass a hard commitment before then. This change takes the five lockfiles osv-scanner reads
(the same recursive scan G05 runs) from 175 findings to 45, with no HIGH left except three that
need a major upgrade their only consumer cannot take yet. Those three get narrow waivers pinned
to the vulnerable version, and the blanket waiver is removed. Supersedes dependabot #216.

## Acceptance criteria
- [x] `osv-scanner` over package-lock.json, functions/, web/pitwall/, newgame/ and newgame/functions/ reports no HIGH or CRITICAL outside the three waived titles (175 → 45 findings, 0 critical).
- [x] functions/ has no HIGH (body-parser, @fastify/busboy, node-forge fixed by in-range updates).
- [x] `newgame/functions` (stale) takes only the four in-range fixes (busboy, body-parser, node-forge, source-map-js); its lockfile is otherwise master's.
- [x] Overrides: `ws@^8` → ^8.22.0, `brace-expansion@^1` → ^1.1.21, `@grpc/grpc-js` → ^1.14.5 (root, portal, newgame); sharp devDependency → ^0.35.5.
- [x] `.aidlc/waivers.yaml` has no `GHSA-` blanket; the three G05 waivers name package@version and advisory, give the consumer and the reason, and expire 2027-03-01.
- [x] Severity is the GHSA label osv-scanner reports, which is what G05 blocks on (a few MODERATEs, e.g. uuid GHSA-w5hq-g745-h8pq, carry a CVSS score of 7.5; they warn, not block).
- [x] The project test command passes: jest 741/741, functions 257/257, rules 87/87, scripts 298/298, portal 172/172 plus its build, workers.
