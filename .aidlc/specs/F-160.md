# F-160 — UC: replace functions.config() before its March 2027 retirement

Created: 2026-11-17 · Status: planned

## Goal

`functions/src/admin/setAdminClaim.ts` still reads its bootstrap secret from `functions.config()`. Firebase retires that API in March 2027 (the repo's own note in `functions/src/purchases/validatePurchase.ts` says so, and the purchase code was moved off it for that reason). Left alone, a functions deploy in the opener's month could fail or lose the value.

Source: the 2026-11-17 EGM review of 2027 readiness (finding R-12); the evidence lines were re-checked against `origin/master` on that date. Dates are proposals worked back from the 2027-03-14 opener, not owner decisions, unless marked.

## Acceptance criteria
- [ ] No call to `functions.config()` remains in `functions/src`; a test or lint rule fails on a new one.
- [ ] The bootstrap secret is read from a declared secret, or the bootstrap path is removed if it is no longer needed (decide which and say why).
- [ ] Deployed through an op; the admin claim path is exercised once afterwards.
