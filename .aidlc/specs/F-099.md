# F-099 — UC: Archivo wide display type in the app

Created: 2026-10-04 · Status: building

## Goal
Undercut (root app). The Pit Wall portal moved to Archivo at width 125 (F-097), so the app and the portal no longer share a typeface. This feature moves the app's Grid UI from Unbounded to the same Archivo face at the same three weights, with no layout change, so the two read as one product.

## Acceptance criteria
- [ ] `assets/fonts/ArchivoExpanded_{400Regular,700Bold,900Black}.ttf` are static instances of the Archivo variable font at width 125, generated by `scripts/design/make-archivo-expanded.sh` (fonttools), with the OFL text beside them and an `.aidlc/assets.yaml` entry.
- [ ] `S_FONT_FAMILY.ui` names the three Archivo families; nothing else in `src/simple/**` references Unbounded; JetBrains Mono is unchanged.
- [ ] Fonts load through `expo-font` `useFonts` with `require`, and the `expo-font` config plugin embeds the three files; `@expo-google-fonts/unbounded` is removed from `package.json` and the lockfile.
- [ ] `npx tsc --noEmit` and `npx expo export --platform android` pass (CI's build gate).
- [ ] Grid screens checked on Expo web in dark and light: first-run, Team, Pick Team and League screenshots in `docs/design/grid/verify/F-099-*.png`. Tile names cannot truncate: `GridTile` sets `adjustsFontSizeToFit` with `minimumFontScale` 0.55 on top of the §3 auto-step, and Archivo Expanded Black measures within −2.4% to +5.7% of Unbounded Black at those sizes (HULKENBERG +5.7%, VERSTAPPEN +2.5%). Picker rows show VERSTAPPEN and ANTONELLI fitting at 16px. The headless demo flow could not pick drivers or reach Profile, so the filled Team grid and Profile are checked on the next device build.
- [ ] `docs/design/grid/TRANSITION.md` §3 names Archivo as the display face.

No user data.

## Performance budget
Three bundled TTFs (about 120 KB each) replace three of the same size from the npm package; app size unchanged within 10 KB.

## Out of scope
- The legacy `app/(tabs)/**` UI and `src/config/themes.ts` (not Grid; untouched per the Grid handoff rule).
- Any colour or token change.
