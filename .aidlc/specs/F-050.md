# F-050 — UC: Grid theme, fonts, routes and Team screen

Created: 2026-09-18 · Status: planned

## Goal

Undercut's live `(simple)` UI gets the "Grid" redesign handed off on 2026-09-18 (Z:\share\undercut zip, checked in under `docs/design/grid/`: spec `TRANSITION.md`, prototype `grid-prototype.dc.html` is the tie-breaker). This first slice lays the foundation the other Grid features (F-051 League, F-052 Profile, F-053 sign-in, F-055 Picker) build on: the black/grey/red token set replaces the Race Day teal palette in `simpleTheme.ts`, Unbounded and JetBrains Mono replace Inter and Space Grotesk, the single swipe-panel screen becomes real expo-router routes (`app/(simple)/index` Team/League tabs, `picker`, `profile`, `league-manager`, `member/[userId]`) with native stack transitions, and the Team screen is rebuilt as the 2-column tile grid. Until F-051/F-052/F-055 land, the pushed routes host the existing Race Day panels re-tokened, so the app stays usable on master between PRs; no store release is cut until the whole set is merged.

## Acceptance criteria
- [ ] `S_COLORS_DARK` / `S_COLORS_LIGHT` carry the TRANSITION.md §3 values (`background #050505`, `surface #0E0E0E`, `card #1A1A1A`, `border #232323`, `borderLight #1E1E1E`, `borderStrong #333333`, `text.primary #F2F2F2`, `text.muted #7A7A7A`, `primary #FF2E2E`, `positive #4ADE80`; light `#FFFFFF / #F4F4F2 / #E8E8E5 / #D6D6D2 / #DDDDD9 / #C8C8C4 / #0A0A0A / #6B6B6B / #FF2E2E / #15803D`). Existing keys the Race Day components still read (`primaryFaint`, `gold`, `ace`, `locked`, `scrim`, …) keep a value so untouched panels still render.
- [ ] `S_FONT_FAMILY` exposes Unbounded 400/700/900 and JetBrains Mono 500/700 (`@expo-google-fonts/unbounded`, `@expo-google-fonts/jetbrains-mono`), loaded in `app/_layout.tsx` with `useFonts`, listed in the `expo-font` config plugin, and `scripts/release/build-uc-aab.sh` expects the new embedded file count. No file under `src/simple/**` or `app/(simple)/**` pairs a loaded family with `fontWeight` (legacy `app/(tabs)` and `(auth)` are out of scope until F-053).
- [ ] `S_TEAM_ACCENTS` adopts the design hexes (McLaren `#FF8000`, Ferrari `#E80020`, Red Bull `#3671C6`, Mercedes `#27F4D2`, Williams `#64C4FF`, Aston Martin `#229971`, Racing Bulls `#6692FF`) and keeps Alpine, Haas, Audi, Cadillac; `teamAccent()` prefers the remote-config `teamColors` primary when present.
- [ ] `app/(simple)/_layout.tsx` is a native Stack with `slide_from_right` for pushed screens; `index` hosts the TEAM / LEAGUE tab pill (both panels stay mounted, switch is a 150 ms cross-fade, no swipe gesture). `app/index.tsx` still redirects to `/(simple)`; a `join` deep link lands on the LEAGUE tab with its `code` pre-filled in the join form.
- [ ] Pixel values in the next two criteria are verified by the Expo-web screenshot pass (396×856) checked in under `docs/design/grid/verify/`; CI checks the derived state only.
- [ ] Team screen matches §4: mono status row (`RD n / N · <CITY>` left, red lock status right, N = races in the season from remote config, countdown from `useLockoutStatus`), 26 px Unbounded 900 title (tap to rename inline), 36 px avatar chip → `/profile`, 3 px season progress bar, SEASON PTS 56 px + LAST RACE 22 px red + RANK `n/N` cells, `LINEUP · SET / n OPEN / LOCKED` label with `EDIT →` → `/picker`.
- [ ] Six 132 px tiles in a 2-column grid: driver tiles show car number, `AUTO` pill when `isReservePick`, season pts, name (19 → 17 → 15 px by length), team-colour bar, contract dots (`contractLength` total, `contractLength − racesHeld` filled, red when 1 left), trend `▲ / ▼ / •` vs the previous race; the constructor tile has the red outline and `TEAM` label; open slots are dashed with a red `+` and route to `/picker`; `ACE` pill (white on red) marks the ace, tap toggles it unless `aceLocked`.
- [ ] Second-team switcher survives as a mono row under the title (only when the user has or may create a second team).
- [ ] `computeTiles` / `formatLockStatus` / `contractDots` are pure helpers in `src/simple/grid/` with jest coverage for: full lineup, 2 open, locked, auto pill, dots at 1 left, trend up/down/flat, lock label under 1 h / hours / days.
- [ ] `npx tsc --noEmit` and `npx jest --ci` pass; `npx expo export --platform android` succeeds.

## Targets

## Data
No new user data. Reads existing team, league-member, race-score and remote-config documents.

## Performance budget
Fonts add five embedded ttf files (≈600 KB). No new network reads on the Team screen beyond today's (team, members, last two race scores). Tab switch < 16 ms of JS work (both panels pre-mounted).

## Out of scope
- Picker, League, League Manager, Profile and sign-in redesigns (F-055, F-051, F-052, F-053).
- Standings movement and best-race data (F-054).
- The legacy `app/(tabs)/**` UI and `src/config/themes.ts`.
