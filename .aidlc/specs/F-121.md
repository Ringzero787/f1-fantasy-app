# F-121 — UC: 2026 season length, calendar times, and scoring-field rules

Created: 2026-10-13 · Status: implemented · Follows F-016 (scoring) and F-086 (calendar)

## Goal
Undercut scoring and the shared Firebase project. The 2026 season scores **23 races** (Saudi cancelled, original Sakhir vacant, Bahrain reinstated at Sepang as round 18). The full-season lock bonus still fired at held ≥ 23, which is unreachable: a driver held from Australia arrives at Abu Dhabi with held = 22. Seed/demo session times for the United States, Las Vegas and Qatar weekends had drifted from OpenF1. Track Limits member docs and Ben model objects in Storage were client-writable, so a signed-in player could rewrite a league table or overwrite the book's files.

## Acceptance criteria
- [x] **`LOCK_BONUS.FULL_SEASON_RACES` is 23** in `functions/src/scoring/scoringCore.ts` and `src/config/constants.ts`. `calculateLockBonus(22)` returns the 100-pt bonus; `calculateLockBonus(21)` does not (`functions/test/scoringCore.test.js`).
- [x] **`season.totalRaces` is 23** in the seeder and the bundled demo calendar. `functions/test/seedDataCalendar.test.js` asserts 23 live (non-cancelled) races.
- [x] **USA, Las Vegas and Qatar session times match OpenF1** (Austin race 2026-10-25T20:00Z, Las Vegas 2026-11-22T04:00Z, Qatar 2026-11-29T16:00Z) in `functions/src/seedData.ts` and `src/data/demoData.ts`. Production continues to take times from `syncRaceSchedules`.
- [x] **`seasonLockTeam` counts remaining races on the server** from `races` documents (`upcoming` or `in_progress`). The client no longer supplies `racesRemaining`.
- [x] **`EARLY_UNLOCK_FEE` in client constants is 50**, matching `earlyUnlockTeam`.
- [x] **`SPRINTS_PER_SEASON` is 6** in `src/config/pricing.config.ts` (China, Miami, Canada, Britain, Netherlands, Singapore). `RACES_PER_SEASON` stays 24: that is the 2025 baseline used to open prices.
- [x] **Track Limits members cannot mint or rewrite scoring fields.** Create requires `totalPoints == 0` and `raceWins == 0`; a member update may only change `displayName`. Rules test in `rules-tests/firestore.rules.test.js`.
- [x] **Chat messages cap text at 4000 characters** and a sender cannot change `senderId`.
- [x] **`errorLogs` create is capped** (≤ 20 fields, message ≤ 2000 characters).
- [x] **`ben/models` Storage writes require the admin custom claim.**

No new user data. Rules **restrict** what a client may write: Track Limits `totalPoints`/`raceWins`, chat `senderId`, unbounded `errorLogs`, and Ben model objects. Existing crash reports and chat messages keep their shapes; Track Limits join still writes `totalPoints: 0, raceWins: 0`.
