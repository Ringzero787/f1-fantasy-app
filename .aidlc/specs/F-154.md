# F-154 — UC: season rollover rehearsal and hardening before the production run

Created: 2026-11-17 · Status: planned

## Goal

The rollover op (F-150) is merged and has never run in full: its first complete execution would be the production one, after which teams are reset. It also writes its groups in the order teams, leagues, prices, calendar (`functions/src/season/rollover.ts`), so for the length of the run a reset team can buy at 2026 prices. This feature proves the op off production first and closes the gaps that a rehearsal would otherwise only find live.

Source: the 2026-11-17 EGM review of 2027 readiness (finding R-05); the evidence lines were re-checked against `origin/master` on that date. Dates are proposals worked back from the 2027-03-14 opener, not owner decisions, unless marked.

## Acceptance criteria
- [ ] The rollover is run with `--apply` against a copy of production (the emulator loaded from an export, or a scratch project), then run again after an induced mid-run failure, then rolled back; each of the three ends in the state the F-150 runbook describes, and the result is written into the F-150 spec.
- [ ] A 2.8.0 app build and the portal are pointed at the rolled-over copy and the Team, Market, League and Pit Wall screens are checked; what they show is recorded.
- [ ] Prices are written before any team is reset, or roster and market writes are locked for the run; a test pins the order or the lock.
- [ ] The op refuses to run while any completed 2026 race lacks its `raceScores` rows, and while any 2026 Moonshot is not in a terminal state; both are covered by tests on the pure planner.
- [ ] The backup path list is a file the op reads, not a parameter pasted from dry-run output.
- [ ] The runbook in F-150 names a point of no return and what "fix forward" means after it.
- [ ] It is confirmed, and recorded where, that a project-level Firestore export or point-in-time recovery exists; if not, one is taken before the run.
- [ ] What the rollover does to Track Limits, which reads `races` and `drivers` in the same project, is written down after reading its code.
