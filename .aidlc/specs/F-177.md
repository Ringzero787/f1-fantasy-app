# F-177 — UC: iOS UIScene lifecycle adoption (iOS 27 SDK)

Created: 2026-11-26 · Status: planned

## Goal

iOS 27 does not launch an app linked against the iOS 27 SDK unless the app has adopted the UIScene lifecycle (`UIApplicationSceneManifest` plus a scene delegate). Expo SDK 55 does not generate one. App Review rejected 2.10.0 build 65 (Xcode 27.2) on 2026-11-26 because it crashed at launch in `_UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption`.

Since #335, iOS store builds use Xcode 26.x. That only works until Apple requires the iOS 27 SDK for uploads, expected around April 2027. Undercut has to adopt scenes before then. The planned January 2027 Expo SDK upgrade is the natural place, if that SDK generates the scene delegate; otherwise a config plugin will add one.

## Acceptance criteria
- [ ] A Release build linked against the iOS 27 SDK carries `UIApplicationSceneManifest`. It launches and stays up on the iOS 27 simulator on both iPhone and iPad (screenshot).
- [ ] These still work under scenes, each verified on the simulator:
  - [ ] custom-scheme deep links;
  - [ ] invite universal links (F-113);
  - [ ] Google and Apple sign-in;
  - [ ] the purchase sheet;
  - [ ] push permission;
  - [ ] dark mode and orientation.
- [ ] `UC_XCODE` defaults back to the standard Xcode, and the post-export guard in `uc-ios-archive.sh` passes on that build.
