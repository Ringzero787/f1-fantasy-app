# F-063 — UC: League Pro head-to-head fixtures

Created: 2026-09-18 · Status: planned

## Goal
Undercut (root app), League Pro only. Members of a Pro league are paired against one league-mate each race and ranked on a win-loss-draw table beside the normal points table, so mid-table teams still have a result to chase every weekend.

## Acceptance criteria
- [ ] When a Pro league enables head-to-head, the server generates a round-robin schedule for the remaining races (bye for odd member counts) and stores it under the league.
- [ ] After each race the server settles fixtures from the F-062 race results: 3 for a win, 1 for a draw; idempotent on re-score.
- [ ] Members joining or leaving mid-season regenerate only future fixtures; settled fixtures never change.
- [ ] League screen shows this week's matchup, the H2H table and past results; hidden with an upsell row in non-Pro leagues.
- [ ] Fixtures and the H2H table are server-written only (rules test); functions reject enabling H2H when `isLeaguePro` is false.

## Targets
- firebase (functions, rules)
- android
- ios

## Data
Derived league results only.

## Performance budget
Settlement adds at most one batched write per Pro league per race.

## Out of scope
- Playoffs or knockout brackets.
- H2H in public leagues with bots.
