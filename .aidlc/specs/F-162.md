# F-162 — UC: 2027 opener go/no-go checklist and an off-box alarm

Created: 2026-11-17 · Status: planned

## Goal

There is no list of what must be true on the morning of the first 2027 lock, and the only alarm for Pit Wall and for held results runs on the same box it watches: on 2026-11-17 that box lost its network twice in a morning. If the box is down, the worker, the hourly check and its email all go quiet together.

Source: the 2026-11-17 EGM review of 2027 readiness (finding R-16, and the plan item for 2027-03-12); the evidence lines were re-checked against `origin/master` on that date. Dates are proposals worked back from the 2027-03-14 opener, not owner decisions, unless marked.

## Acceptance criteria
- [ ] A checklist in `docs/RUNBOOK.md` for the opener: the lock fires, the first result is ingested and scored, auto-fill ran, the alert path works, the portal shows round 1; each with how to check it.
- [ ] Something outside the build box notices when the worker heartbeat (`pw_status/worker`) or the hourly check goes quiet, and tells the owner.
- [ ] A written way to run an op from a second machine if the box is down on a race weekend, or a written decision that there is none.
- [ ] The checklist is run once as a dry rehearsal before 2027-03-12.
