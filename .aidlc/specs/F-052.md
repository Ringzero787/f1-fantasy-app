# F-052 — UC: Grid Profile screen

Created: 2026-09-18 · Status: planned

## Goal

The profile sheet becomes a full pushed screen (`app/(simple)/profile.tsx`) in the Grid design: 72 px avatar, name, red mono status line (`P1 · <LEAGUE>`, `RACING SOLO`, or `DEMO MODE` in demo), rows NAME, TEAM NAME, AVATAR, LEAGUE, APPEARANCE, then the folded-in rows from today's sheet (Game Rules, Race History, Team reminders, Display size, Privacy Policy, Delete account, version), three stat cards and the outline SIGN OUT pill. Photo and AI avatars stay: the avatar chip and the 72 px avatar show the image when one exists, initials otherwise, and the AVATAR row offers Generate with AI / Choose from library.

## Acceptance criteria
- [ ] Header `← BACK` / `SEASON 2026`, title `Profile`; avatar 72 px (image or initials), display name 20 px, red mono status line: `P<rank> · <LEAGUE NAME>` when in a league, otherwise `RACING SOLO`.
- [ ] Rows in §4 style: NAME (inline edit), TEAM NAME (inline edit), AVATAR (Generate with AI / Choose from library, existing services), LEAGUE (`Join or create` in red until joined, pushes `/league-manager`), APPEARANCE pill with AUTO / DARK / LIGHT segments bound to `prefsStore.themeMode`, DISPLAY SIZE pill (S/M/L/XL = the existing 0.85/1.0/1.15/1.3 steps), TEAM REMINDERS ON/OFF.
- [ ] Folded rows below the stat cards: GAME RULES (existing RulesGuide), RACE HISTORY (inline per-round breakdown with the tenure rule), PRIVACY POLICY, DELETE ACCOUNT (red text, existing confirm flow), version caption. Pixel values are verified by the screenshots in `docs/design/grid/verify/`.
- [ ] Stat cards sit under APPEARANCE / DISPLAY SIZE / TEAM REMINDERS as in the prototype: RACES `n/N` (distinct race ids in the server-stamped `scoredRaces` / season length, local history as fallback), AVG / RACE (season points ÷ scored races), BEST (`bestRacePoints` from the server, `—` until F-054 writes it).
- [ ] SIGN OUT outline pill calls the existing sign-out and lands on `/(auth)/login`.
- [ ] `SimpleProfileSheet` is deleted (`SimpleProfilePill` went in F-050); nothing else imports it.
- [ ] `profileStatusLine(rank, leagueName)`, `teamRaceHistory`, `historyStats` and `scoredRaceCount` are pure helpers with jest coverage.
- [ ] `npx tsc --noEmit` and `npx jest --ci` pass; `npx expo export --platform android` succeeds.
