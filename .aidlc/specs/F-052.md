# F-052 — UC: Grid Profile screen

Created: 2026-09-18 · Status: planned

## Goal

The profile sheet becomes a full pushed screen (`app/(simple)/profile.tsx`) in the Grid design: 72 px avatar, name, red mono status line (`P1 · <LEAGUE>` or `FREE PASS`), rows NAME, TEAM NAME, AVATAR, LEAGUE, APPEARANCE, then the folded-in rows from today's sheet (Game Rules, Race History, Team reminders, Display size, Privacy Policy, Delete account, version), three stat cards and the outline SIGN OUT pill. Photo and AI avatars stay: the avatar chip and the 72 px avatar show the image when one exists, initials otherwise, and the AVATAR row offers Generate with AI / Choose from library.

## Acceptance criteria
- [ ] Header `← BACK` / `SEASON 2026`, title `Profile`; avatar 72 px (image or initials), display name 20 px, red mono status line: `P<rank> · <LEAGUE NAME>` when in a league, otherwise `RACING SOLO`.
- [ ] Rows in §4 style: NAME (inline edit), TEAM NAME (inline edit), AVATAR (Generate with AI / Choose from library, existing services), LEAGUE (`Join or create` in red until joined, pushes `/league-manager`), APPEARANCE pill with AUTO / DARK / LIGHT segments bound to `prefsStore.themeMode`.
- [ ] Folded rows: GAME RULES (existing RulesGuide), RACE HISTORY, TEAM REMINDERS (push toggle, existing notification service), DISPLAY SIZE (existing scale options), PRIVACY POLICY, DELETE ACCOUNT (red text, existing confirm flow), version caption.
- [ ] Stat cards: RACES `n/N` (races the team has been scored for / season length), AVG / RACE (`pprAverage` or total ÷ scored), BEST (renders `—` until F-054).
- [ ] SIGN OUT outline pill calls the existing sign-out and lands on `/(auth)/login`.
- [ ] `SimpleProfileSheet` and `SimpleProfilePill` are deleted; nothing else imports them.
- [ ] `profileStatusLine(rank, leagueName, freePass)` is a pure helper with jest coverage.
- [ ] `npx tsc --noEmit` and `npx jest --ci` pass; `npx expo export --platform android` succeeds.
