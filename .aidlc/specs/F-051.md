# F-051 — UC: Grid League standings and League Manager

Created: 2026-09-18 · Status: planned

## Goal

The LEAGUE tab and the league admin surface get the Grid design. Standings become the monochrome `POS · PLAYER` list with the player's own row in red and a SEASON / LAST RACE sort toggle; a player with no league sees "Racing solo." with Create / Join cards. League creation, joining by code, the invite code card and league settings move into `app/(simple)/league-manager.tsx` (steps `none → join | create → done`), reached from Profile → LEAGUE and from the empty-state cards. Tapping a standings row pushes the read-only member team view (`member/[userId]`) reusing the F-050 tile grid.

## Acceptance criteria
- [ ] Standings rows follow §4: rank 30 px (red for the signed-in user), movement cell (renders `—` until F-054 supplies previous ranks), name + team, points, `LEADER` in red or the gap `-33`. Header shows the league name and `n PLAYERS` (League Manager shows `n / max`); the sort toggle switches value and ordering.
- [ ] Empty state: `Racing solo.` 40 px, muted copy, Create card (card fill, red `+`) and Join card (outlined) push League Manager at the matching step.
- [ ] League Manager `join`: mono uppercase code input, JOIN LEAGUE enabled at ≥ 6 chars, uses `joinLeagueByCode`; errors render inline in red mono. Deep link `join=true&code=` opens this step pre-filled.
- [ ] League Manager `create`: name input (3–50 chars) and CREATE LEAGUE; leagues are created with `DEFAULT_MAX_MEMBERS` (no size chips).
- [ ] League Manager `done`: invite-code card (red outline, 34 px mono code, `n / max PLAYERS`), EMAIL (invite modal writing `leagues/{id}/invites` as before), SMS (the `sms:` composer, falling back to the OS share sheet, with the code and the `/join?code=` link), COPY (clipboard, label `COPIED` 1.5 s); settings rows NAME, PLAYERS, OWNER; a `LEAGUE SIZE` row visible only to the league creator that shows `n / max` and opens the existing expansion purchase (`PurchaseModal`; credit consumed then `+SLOTS_PER_EXPANSION` via the demo-aware store, no upper bound); red `LEAVE LEAGUE` / `DELETE LEAGUE` text link with a confirm.
- [ ] Member team view: Team screen layout, no EDIT link, no open-slot taps, header = the member's team name and display name, tiles from their roster.
- [ ] `SimpleLeaguePanel`, `SimpleStandingsRow` and `SimpleMemberTeamView` are replaced; the live standings listener from F-045 is kept.
- [ ] `rankStandings(members, sortBy, userId)` is a pure helper in `src/simple/grid/` with jest coverage: season vs last-race order, leader gap, own-row flag, tie order.
- [ ] `npx tsc --noEmit` and `npx jest --ci` pass; `npx expo export --platform android` succeeds.
