# F-075 — UC: Pit Wall web portal shell and sign-in

Created: 2026-09-19 · Status: planned

## Goal
Undercut (root app). Undercut Pit Wall is a web portal for the fan who wants to stay on top of the sport and their fantasy team without following every outlet. This feature is the shell everything else renders in: same account as the app, the Grid look, and a dense dashboard layout that adapts to what the user clicks instead of growing longer.

## Acceptance criteria
- [ ] Web app lives in `web/pitwall/` (Vite + React + TypeScript), deployed to a second Firebase Hosting site (`pitwall`) on the existing project; the current `public/` marketing/legal site is untouched. Deploy goes through a new `aidlc op` kind (`hosting-deploy`).
- [ ] Sign-in uses the existing Firebase Auth project (email/password, Google, Apple); a user signed in on the web sees the same teams and leagues as in the app. No new account system.
- [ ] Grid design system applied from `docs/design/grid/TRANSITION.md`: tokens for dark and light, Unbounded + JetBrains Mono, radii 18/14/12/999, 1px borders, one red accent, no gradients or shadows; team colours only as small bars/marks. Follows system theme with a manual toggle.
- [ ] Navigation is eight pages: Briefing, Board, Circuit, Pace Lab, Market, Lineup Lab, Season, Wire. A sticky context bar (round, session state, lock countdown, the user's team and budget) drives every widget.
- [ ] **Scroll budget:** at 1440x900 and at 390x844 no page exceeds three viewport heights; enforced by a Playwright test per page. Depth comes from click-ins: a right slide-over for any driver, constructor, circuit or story (master-detail), in-card tabs (L5/L10/Season; Quali/Race/Sprint), column-set presets, and cross-filtering when a team or driver is selected. A pinned compare tray holds up to three entities across pages.
- [ ] Every chart has a hover tooltip and a table view; colour is never the only encoding; keyboard focus is visible; works at 390px width.
- [ ] Footer and sign-in carry the "unofficial, not affiliated" disclaimer; no trademark watchlist term appears in the product, page or tier names.
- [ ] Users without a pass see the shell with the free teaser set defined in F-068.

## Targets
- web

## Data
Reads the signed-in user's existing teams, leagues and profile. Stores UI preferences (theme, saved views, compare tray) on the user document.

## Performance budget
First load JS <= 250 KB gzip; Briefing interactive < 2.5 s on a mid-range phone over 4G; every page renders from precomputed documents (<= 12 Firestore reads per page view).

## Out of scope
- Live timing during sessions.
- Native app embedding of portal pages.
