# F-172 — UC: compare every race of the season with the official classification

Created: 2026-11-24 · Status: shipped

## Goal
F-168 compares a race with the provider's official classification for 7 days after it, so a penalty or appeal decided later goes unnoticed. The first comparison of every 2026 race (2026-11-24) found 7 races that differ, none of which had been seen. The ops check should look at the whole season, without emailing every day about differences already decided.

## Acceptance criteria
- [x] Races from the last 7 days are compared on every hourly run. Every completed race of the season is compared once a day, on the 07 UTC run or with `PW_CHECK_DEEP=1` (`isDeepRun`, tested in `scripts/ops/pitwall-check.test.js`).
- [x] Each race's own live-sweep car map comes first. The ingestion `DRIVER_NUMBER_TO_ID` sits under it, but only for its own season, `DRIVER_TABLE_SEASON` (`carMapFor`, tested).
- [x] A missing `functions/lib` build is a WARN on each race it leaves uncompared, never a silent OK (tested).
- [x] On the daily pass, a provider error on an older race marks that race unchecked and does not stop the whole check. A recent race keeps the old behaviour.
- [x] Differences already decided are acknowledged by their **exact** set in `ACKNOWLEDGED_DRIFT`. A race stays quiet only while its differences are exactly that set, and any further change fails again (tested). Owner decision, 2026-11-24:
  - Mexico R21 and Azerbaijan R17 are real post-race penalties. They will be corrected after the season (F-173).
  - Monaco R8 and Britain R11 are real penalties, but those races have no raceSnapshots, so they cannot be corrected.
  - Australia R1, China R2 and Canada R7 differ only because of DNS/NC handling added to our scoring later (2026-06-13 and 06-30). They were scored under the rules then and are not corrected.
- [x] A FAIL on an older race does not point at `correctRaceResults.js`, which only fixes the latest race. It points at F-173 or the acknowledged list (tested).
- [x] Run read-only against production with `PW_CHECK_DEEP=1`: every 2026 race is either compared clean or acknowledged.
- [x] `/data/f1-app-openf1` (the ops box) is moved to the merge commit and runs `npm --prefix functions run build`, so the car table is present. **Done** 2026-11-24 (at 17f9acd).

## Targets
- Ops box only: `scripts/ops/pitwall-check.js`, `scripts/ops/pitwall-check-lib.js`. No app, function or rules change.

## Data
Read-only: `races`, `races/{id}/live/positions`, and OpenF1 `/session_result`. No personal data.

## Performance budget
The daily pass makes about 25 extra OpenF1 requests at 1.5 s spacing, adding roughly 40 s to one run a day. That is well inside the script's 600 s timeout.

## Out of scope
- Correcting any of the acknowledged races (F-173).
- 2027: the table follows `DRIVER_TABLE_SEASON` (F-156). The acknowledged list is per race id, so it does not carry over.
