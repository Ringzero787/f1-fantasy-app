# uc-v2.4.3 — 2026-10-04

Undercut 2.4.3：统一账户、购买安全性与 Pit Wall 高级功能。

## 新增

- 跨商店登录：无论你从 Google Play、App Store 还是 Amazon Appstore 安装，账户都能通用
- 可直接从应用内分享联赛排名和你的车队
- 商店退款后，Pit Wall Pass 权益将被撤销
- 应用内新增车手详情，显示你的通行证购买了什么
- Pit Wall Briefing 全新改版，包含主视觉区、要闻速览栏和价格变动榜

## 变更

- Ace 锁定现在读取服务器日历，而非内置日历
- Pit Wall 预测现包含下限、中位数、上限、退赛风险及下一次价格预估
- Pit Wall Pass（每赛季 $14.99）为唯一高级产品；League Pro 权益由通行证所有权派生

## 修复

- **安全性**：伪造的 Play Store 令牌将无法再以错误价格购买卡包或通行证
- **安全性**：移除生产环境 API 密钥的回退机制；配置出错时不再静默降级
- Ace 窗口现在会在其计分的每个赛段冻结，而不仅限于正赛
- 登录交接现已锁定至发起登录的设备
- 购买现在按每笔交易授予一次，而非每次启动应用授予一次
- 撤销后再次授予通行证现已可正常运作
- 商店队列中滞留的购买现在能正确完成
- 修正了赛段映射；巴林大奖赛已作为 R18 重新归入雪邦赛道
- 九个运维脚本在导入时不再静默失败
- 车队 SHARE 字段现在作为控件读取，而非标题文字
- 已停止种子数据导入；日历现已正确
- iOS 构建版本不再提供 Amazon Appstore 选项

## 安全性

- Ace 锁定已迁移至服务器端；移除仅限应用内的实现
- Amazon 与 Apple 的共享密钥已迁移至 Secret Manager
- Amazon 收据 ID 现使用其自有格式，而非 Play Store 的格式
- 已清除高危依赖项安全警告
- 所有导入时防护与逃逸类问题现已全部关闭
