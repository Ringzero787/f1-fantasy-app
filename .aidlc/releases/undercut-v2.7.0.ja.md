# uc-v2.7.0 — 2026-10-26

Undercut 2.7.0：ラインナップがロック中でもマーケットは開いたまま、週末のまとめにあなたのMoonshotが表示され、Moonshotカウンターはロック時に数え、Pit Wallのエース推奨がドライバーシートの先頭に来ます。サーバー側では、タイミングフィードを有料キーで読むようになったため結果が時間どおりに届きます（これにビルドは不要です）。

## 追加

- **ロック中のマーケット。** チーム行のMARKETで、レース週末のあいだピッカーを読み取り専用のマーケットとして開けます：価格、ポイント、予測が見られ、タップするものはありません。保存バーにはLOCKED · AUTO-FILL ONと表示されます。
- **週末のまとめにMoonshot。** 週末のポイントと得点者の間のカードに、あなたのコール、ドライバーの順位、ポイントが表示され、1行でロスターとMoonshotを週末の合計にまとめます。現金の賭けは現金として示され、無効の場合はトークンが戻ったと表示されます。
- **レース当日のライブスコア（オフ）。** レース中に各タイルへLIVE +N、統計にLIVE · SO FARを出すコードはこのビルドに含まれていますが、タイミング提供元の書面による確認のあとライブタイミングのスイッチが入るまで何も表示されません。

## 変更

- **Moonshotカウンター。** トークンは置いたときではなく、コールがロックされた時点で使用済みと数えます。開いているコールは全額返金でまだキャンセルできるためです：ONE IN PLAY · COUNTS WHEN SELECTIONS LOCK、その後ONE USED THIS WEEKEND。
- **エース推奨を先頭に。** Pit WallのACE CALLがドライバーシートの最初のブロックになり、ドライバー名とチームの直下に来ます。このドライバーをエースにする推奨のときはMAKE ACE · 2× POINTSがそこにあり、下部のボタンは表示されません。
