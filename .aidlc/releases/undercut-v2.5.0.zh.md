# uc-v2.5.0 — 2026-10-07

Undercut 2.5.0 带来了 Moonshot 赛事预测、车队名称编辑功能,以及实时计时方面的改进。

## 新增

- **Moonshot**:从第13轮起,在联盟中落后的车队可以为下一场比赛对一位车手做出一次预测——夺冠、登上领奖台、拿分或击败对手——并投入部分赛季积分或阵容预算。预测命中,奖励计入赛季总分;预测落空,投入即失。车队和联盟视图均已支持,并提供首次使用引导。
- 新增比赛日实时计时数据接入,通过 Firestore 分布式架构实现实时更新。
- 现可在 Pit Wall 门户中重命名你的车队和车队经理显示名称;更改会同步到你的所有设备。
- 应用内新增 Archivo 字体,与 Pit Wall 网页门户保持一致。

## 变更

- 车队元数据同步更加智能:现在只会将设备本地的更改上传至 Firestore,避免其他设备上的编辑被回退覆盖。
- 应用内显示的阵容锁定时间现与服务器强制执行的锁定时间保持一致。

## 修复

- 在 2.5.0 发布前完成安全审查加固。
- 修复创建联盟后未经正确授权即可获得付费功能的问题。
- 车队联盟 ID 现会校验为可用的 Firestore 文档 ID。
- 修复定期更新时元数据同步会覆盖服务器上较新版本的问题。
