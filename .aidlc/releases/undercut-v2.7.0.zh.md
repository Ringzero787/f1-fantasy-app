# uc-v2.7.0 — 2026-10-26

Undercut 2.7.0：阵容锁定期间市场保持开放，你的 Moonshot 出现在周末回顾中，Moonshot 计数器在锁定时计数，Pit Wall 的王牌建议位于车手页顶部。服务器端，计时数据源现在用付费密钥读取，比赛结果能按时到达（这不需要新版本）。

## 新增

- **锁定期间的市场。** 车队行上的 MARKET 会在整个比赛周末以只读市场的形式打开选择器：价格、积分和预测，没有可点击的操作。保存栏显示 LOCKED · AUTO-FILL ON。
- **周末回顾中的 Moonshot。** 周末积分与得分者之间的卡片显示你的预测、车手名次和积分，并用一行把阵容和 Moonshot 相加成周末总分。现金投注标注为现金；作废时会说明代币已退回。
- **比赛日实时得分，已关闭。** 比赛期间在每个磁贴显示 LIVE +N 和统计栏显示 LIVE · SO FAR 的代码已包含在此版本中，但在计时数据提供方书面确认并开启实时计时开关之前不会显示任何内容。

## 变更

- **Moonshot 计数器。** 代币在预测锁定时计为已用，而不是在你下注时，因为未锁定的预测仍可全额退款取消：先显示 ONE IN PLAY · COUNTS WHEN SELECTIONS LOCK，之后显示 ONE USED THIS WEEKEND。
- **王牌建议优先。** Pit Wall 的 ACE CALL 成为车手页的第一个区块，位于车手姓名和车队之下；当建议是把该车手设为王牌时，MAKE ACE · 2× POINTS 就在那里，底部按钮不再显示。
