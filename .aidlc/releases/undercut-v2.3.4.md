# uc-v2.3.4 — 2026-09-24

Undercut 2.3.4 adds per-race league leaderboards with race wins, and an R8-optimised Android build.

## Added

- Per-race league leaderboard: the League screen's SEASON toggle is now a selector for season, last race, or any race with a recorded leaderboard; race wins show on the season table (F-062)
- Per-race roster and Ace snapshots, written by the server from round 17 on (F-029)

## Changed

- Android release builds use R8 minification and resource shrinking: a smaller install and a leaner native side

## Not in this app release

- The Pit Wall web portal (F-075) is separate from the app and is not part of this build
- F-059 step B (scoped team reads, owner-only member count) is still not in force
